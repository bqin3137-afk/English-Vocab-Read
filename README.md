# 英语单词带读学习网页 (English Vocab Read)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Pure Frontend](https://img.shields.io/badge/Architecture-Pure%20Frontend%20HTML%2FCSS%2FJS-emerald.svg)](#)
[![Zero Tracking](https://img.shields.io/badge/Privacy-100%25%20Local%20%26%20Zero%20Telemetry-purple.svg)](#)

一个**单文件、零后端依赖、支持离线运行**的英语单词带读学习网页应用。专为日常背单词、四六级词汇复习与听音跟读设计，使用浏览器原生语音合成 (`Web Speech API / speechSynthesis`) 实现中英双语自动切换朗读。

## 一、核心特性

1. **内置 5,300+ 核心词根与智能词形还原引擎**
   - 内置初高中及大学英语四六级（CET-4 / CET-6）高频核心词库（覆盖 A–Z 全部字母，共 5,304 个核心词根）。
   - 内置客户端形态学词形还原算法（支持不规则动词映射、复数 `-s/-es/-ies/-ves`、过去式/分词 `-ed/-ied/-ing`、副词 `-ly`、名词与形容词后缀 `-ment/-ness/-tion/-able/-ful/-less`、常见否定与派生前缀 `un-/in-/im-/dis-/re-` 等），总计可识别 **20,000+ 英语单词及派生变体**。
2. **多词性智能语音转换（无乱读字母 Bug）**
   - 自动将多词性释义中的英文词性缩写（如 `practice v. 练习、实践；n. 实践、练习` 中的 `v.`、`n.`、`adj.`、`adv.`、`vt.`、`vi.`、`prep.` 等）转换为自然中文语音（“动词：……，名词：……”），同时精准识别词界，绝不误伤用户自定义的普通英文字符。
3. **中英独立带读参数调节（全局实时生效）**
   - **朗读语速**：`0.5× ～ 2.0×`（步进 `0.1×`，默认 `1.0×`）。
   - **英文朗读次数**：`1 ～ 3 次`（默认 `1 次`）。
   - **中文朗读次数**：`1 ～ 3 次`（默认 `1 次`）。
   - **单词间隔时间**：`0.5 秒 ～ 3.0 秒`（步进 `0.1 秒`，默认 `1.0 秒`）。
   - **单次带读上限**：支持切换 `50 词（扩充模式，默认）` 与 `10 词（经典模式）`，超出上限自动截取并提示。
4. **翻译内容实时可编辑**
   - 每个单词右侧均配有可编辑释义框，修改后带读朗读**实时以修改后的内容为准**，并支持一键恢复默认释义。
   - 未收录生词自动高亮提示「未找到翻译，请手动填写」，填写后即可正常带读。
5. **完整播放控制与并发安全**
   - 支持「开始带读 / 暂停 / 继续 / 停止 / 上一个 / 下一个」及单卡片独立试听，内置 `runId` 异步会话锁，连续快速点击绝不产生重音或竞态卡死。
   - 支持键盘快捷键：`Space`（播放/暂停）、`←`（上一个）、`→`（下一个）。

## 二、快速使用与部署指南

### 1. 本地直接运行
无需安装 Node.js、Python 或任何构建工具。直接双击打开 `index.html`（或 `english_vocab_reader.html`）即可在浏览器中使用。

### 2. 部署到 GitHub Pages 并绑定自定义域名
1. 在 GitHub 新建公开仓库（例如 `english-vocab-reader`），上传本仓库中的 `index.html`、`README.md`、`LICENSE`。
2. 进入仓库 **Settings → Pages**，在 **Build and deployment** 下选择 `Deploy from a branch`，分支选择 `main` / `/ (root)` 并保存。
3. **绑定个人域名（可选）**：
   - 在你的域名服务商后台（Cloudflare / 阿里云 / 腾讯云 / GoDaddy 等）添加一条 `CNAME` 记录，指向 `<你的GitHub用户名>.github.io`。
   - 回到 GitHub Pages 设置页的 **Custom domain** 填入你的域名并勾选 **Enforce HTTPS**，等待数分钟即可通过专属链接访问。
